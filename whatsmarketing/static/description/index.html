Key Features

Send WhatsApp from CRM

Send WhatsApp messages directly from any Lead, Contact, or Customer record with one click.

Send pre-approved WhatsApp Business templates to your leads and customers for outreach and notifications.

Message History

Every sent message is logged with delivery status and saved as a chatter note on the related record.

How It Works

1. Configure Your API Key

Sign up for a WhatsMarketing account at whatsmarketing.in, get your API key from the developer console, and enter it in Odoo Settings.

2. Send from Any Record

Open any Lead, Contact, or Customer in Odoo CRM and click the "Send WhatsApp" button to compose and send a message.

3. Choose Text or Template

Send a free-text message (within the 24-hour WhatsApp conversation window) or send any pre-approved template by its ID.

4. Track Every Message

View the WhatsApp message log directly from each record's chatter, or browse all messages from the WhatsMarketing menu.
